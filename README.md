# Shayan Majidy — personal website

Jekyll source for the GitHub Pages site. The package is checked using local Chromium fixtures built from its actual page markup, CSS and JavaScript. This is not a full Jekyll build or a live deployment test. The required Ruby/Jekyll dependencies were not available in the build workspace. Keep your backup branch and verify the GitHub Pages build after upload.


## Content map

- `_pages/about.md`: homepage identity, research directions, teaching/mentoring, and background.
- `_pages/publications.md`: the existing bibliography, now on its own page. Add public papers here; keep preprints clearly labelled.
- `_pages/oot-and-aboot.md`: photographs and captions (unchanged in this revision).
- `_data/navigation.yml`: navigation links. Research/Teaching point to homepage sections.
- `assets/css/main.css`: shared responsive styling. Homepage/publications: 860px; gallery: 920px at desktop sizes.
- `CV.pdf`: printable CV. In this revision, only the misspelled email address was corrected.

The research summaries distinguish aims from established results. There are no placeholders for unpublished papers or claims of unannounced results. The 2.25-second opening is unchanged.
